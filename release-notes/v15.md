Barrelbot v15 for **Minecraft 1.21.11**.

## What's new

- Migrated datapack and resource pack to Minecraft 1.21.11 pack formats
- Updated item commands and predicates to data components
- Converted custom item models to the 1.21.4+ `items/` range-dispatch format

## Install

1. Download both release assets:
   - `barrelbot_data_pack_v15.zip`
   - `barrelbot_resource_pack_v15.zip`
2. Extract the datapack zip into your world's `datapacks` folder.
3. Extract the resource pack zip into your `resourcepacks` folder.
4. Enable the resource pack in world settings.
5. Run `/reload` or restart the world.

## Notes

- Requires Minecraft Java Edition **1.21.11**
- This release is built from the migrated `build/` output and does not require the private KMC Beet build chain to install
